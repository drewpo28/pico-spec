# Test images

> [Русский](../ru/images.md) · [Home](README.md)

Images are **not stored in the repository** (to keep it lightweight) — this page
only lists links and what each one verifies. Download the file you need and copy
it to the SD card.

## How to use

1. Find the feature you want to verify in the table below (or on its [menu](README.md) page).
2. Download the image via the link.
3. Load it through **Storage** and follow the "Expected result" column.
