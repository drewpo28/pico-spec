# pico-spec — документация / documentation

Документация устроена по структуре экранного меню (OSD): каждый пункт меню → своя
страница с описанием, схемами подключения, ссылками на оригинальные проекты и
таблицей тестовых образов.

The docs mirror the on-screen (OSD) menu tree: every menu entry → its own page with
description, wiring schematics, links to upstream projects, and a table of test images.
