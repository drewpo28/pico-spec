# Video — Видео

> Путь в меню: **Video** · Платы: все (расширенные пункты — только RP2350) · Требует: —

Настройки видеовыхода и графических режимов. Полный набор пунктов доступен на
RP2350; на RP2040 меню сокращено (нет ULA+, Gigascreen, Timex, DMA, HDMI Dither,
16col — не хватает памяти/ресурсов).

## Опции меню

| Пункт | Значения | Описание |
|-------|----------|----------|
| Mode | 640x480@60 `[6]` · 640x480@50 `[5]` · 720x480@60 `[H]` · 720x576@50 `[F]` | Разрешение и частота кадров VGA/HDMI. Переключение «на лету» без перезагрузки. |
| Palette | варианты палитр | Цветовая палитра ZX. |
| Render type | Standard `[S]` · Snow effect `[A]` | Обычный рендер или эмуляция «снега» (артефакт записи в видеопамять при работе процессора). |
| Aspect Ratio | 4:3 `[4]` · 16:9 `[1]` | Соотношение сторон картинки. |
| Scanlines | Off `[0]` · 1 Darkest · 2 Dark *(умолч.)* · 3 Light · 4 Lightest | Эффект «строчек» ЭЛТ, 4 уровня яркости. |
| V-Sync | On / Off | Вертикальная синхронизация. |
| Gigascreen (No Flick) *(RP2350)* | On / Off | Подавление мерцания gigascreen-изображений. |
| ULA+ *(RP2350)* | On / Off | Расширенная 64-цветная палитра ULAplus. |
| Timex Gfx Mode *(RP2350)* | On / Off | Видеорежимы Timex SCLD: hi-res 512→256 (OR-merge), hi-color, dual-screen. |
| DMA *(RP2350)* | On / Off | Режим вывода через DMA. |
| HDMI Dither (ULA+) *(RP2350)* | On / Off | Дизеринг (Bayer) палитры по HDMI при активном ULA+; применяется через ISR. |
| 16col (Pentagon) *(RP2350)* | On / Off | 16-цветный попиксельный атрибутный режим Pentagon. |

> 💡 Profi DS80 (512×240 hi-res) переключается в подменю модели Profi (STD/DS80),
> а не здесь — см. [Machine](04-machine.md).

## Видеорежимы и вывод

- Вывод: **VGA**, **HDMI** (цифровой), **TV-composite** — зависит от платы.
- **HDMI audio** (RP2350) — звук по HDMI; см. [Audio](02-audio.md).
- Переключение разрешения выполняется через перезагрузку (фрагментация кучи не
  даёт безопасно «вырастить» фреймбуфер на лету).

## Схема / подключение

Видео-пины (база дисплея) для каждой платы — в [Платы и распиновка](../hardware/boards.md).

## Как проверить

| Образ | Что проверяет | Ожидаемый результат |
|-------|---------------|---------------------|
| _(демо с бордюр-эффектами)_ | Тайминги бордюра | Aquaplane / The Sentinel / Overscan рисуются корректно |
| _(Timex hi-color)_ | Timex SCLD | 8×1 атрибуты вместо 8×8 |
| _(ULA+ демо)_ | ULA+ палитра | 64 цвета одновременно |

Полный список — в [каталоге образов](../images.md).
