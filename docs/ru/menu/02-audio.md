# Audio — Звук

> Путь в меню: **Audio** · Платы: все (часть пунктов — только RP2350) · Требует: —

Меню настройки звуковых подсистем эмулятора. Состав пунктов зависит от платы:
на RP2040 нет SAA1099 и MIDI (не хватает ресурсов/пинов), на RP2350 доступен
полный набор.

## Опции меню

| Пункт | Значения | По умолчанию | Описание |
|-------|----------|--------------|----------|
| AY-3-8912 ON/OFF | On / Off | On | Эмуляция звукового сопроцессора AY-3-8912 (128K/Pentagon). |
| AY-3-8912 Stereo | Mono / ABC / ACB | ACB | Стереопанорама трёх каналов AY. ABC и ACB — две стандартные схемы разведения каналов. |
| TurboSound | Off / On | Off | Второй чип AY (6 каналов суммарно) — TurboSound / NedoSound. |
| Covox | Off / … | Off | 8-битный ЦАП Covox на порту. Для игр/демо с PCM-сэмплами. |
| SounDrive | Off / On / Auto | Auto | 4-канальный PCM (Covox-подобный, порты #3F/#5F). Auto = включён только на Profi. |
| SAA1099 ON/OFF *(RP2350)* | On / Off | Off | Эмуляция SAA1099 (стерео, 6 тон-каналов + шум + конверты). |
| MIDI *(RP2350)* | Off / Ext / … | Off | MIDI-выход через UART. См. [MIDI](../hardware/midi.md). |
| Audio Driver | I2S / PWM / … | (зависит от платы) | Способ вывода звука: I2S (внешний ЦАП), PWM, 74HC595 и т.п. |
| Volume Boost | уровни | — | Программное усиление громкости. |

> ⚠️ На платах Murmulator MIDI и реальный вход с ленты делят один пин (GPIO 22):
> при включённом MIDI загрузка с реальной ленты недоступна.

## Подсистемы подробнее

- **AY-3-8912** — эмуляция верифицирована, стерео ABC/ACB.
- **SAA1099** — реализация на основе [stripwax/SAASound](https://github.com/stripwax/SAASound),
  сверена с реальным чипом SAA1099P. Детали модели микширования — в [CLAUDE.md](../../../CLAUDE.md).
- **General Sound (GS)** — выделенный Z80 на core1 с 2 МБ сэмпл-памяти; авто-включается
  на RP2350 с butter PSRAM.
- **PCM5122** — внешний I2S-ЦАП для плат Waveshare PiZero, см. [страницу DAC](../hardware/audio-dac-pcm5122.md).

## Схема / подключение

Распиновка аудио-пинов (I2S/PWM/595) для каждой платы — в [Платы и распиновка](../hardware/boards.md).
