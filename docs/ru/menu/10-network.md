# Network

> Путь в меню: **Network** · Платы: **только RP2350** (RP2040 не поддерживается) · Требует: модуль **ESP-01S** (ESP8266) со стоковой AT-прошивкой + SD-карта

## Что это

Сетевые возможности через модуль **ESP-01S**, подключённый к UART. ESP работает на
**стоковой AT-прошивке Espressif** — перепрошивать его не нужно. На стороне RP2350
реализованы:

- **ZiFi NIC** — сетевой интерфейс для ZX-Spectrum-софта (порт `#EF`, окно 16550-UART).
  Совместим с терминалом/драйверами **MRF** (см. [Софт](#софт)).
- **WiFi** — подключение к точке доступа (скан, пароль). Данные сохраняются и при
  следующей загрузке переподключение идёт автоматически.
- **Синхронизация времени** по SNTP → встроенные часы (RTC / Mr Gluk TimeKeeper) —
  выполняется автоматически сразу после подключения к WiFi и на буте, либо вручную.
  Нужен включённый RTC (**Options → Other → RTC + NVRAM**).
- **File transfer** — клиент **FTP / SFTP / SSH** прямо из OSD: просмотр удалённых
  каталогов, скачивание/закачка файлов на SD, копирование папок, удаление.
  SSH-крипта (curve25519, AES-CTR, HMAC-SHA256) считается на RP2350 через mbedTLS;
  ESP служит TCP-мостом.
- **FTP-сервер** — расшаривание SD-карты в локальную сеть. ПК подключается к
  устройству, просматривает SD и заливает/скачивает файлы (обратное к File transfer).
  Живой лог-терминал показывает активность; эмуляция на паузе, пока не нажмёшь
  **ESC**. Анонимно, только активный режим.

## Структура меню

```
Network
├── ESP01 ▸
│   ├── GPIO ▸            выбор пары пинов UART (TX/RX)
│   ├── Baud ▸            115200 / 230400 / 460800 / 921600
│   ├── Time zone ▸       UTC−12 … UTC+14
│   └── Sync time (SNTP)  разовая синхронизация часов
├── WiFi <статус>         подключиться / отключиться (показывает SSID + IP)
├── File transfer ▸       FTP / SFTP клиент (см. ниже)
├── FTP Server ▸          расшаривание SD-карты в локальную сеть (см. ниже)
└── ZiFi NIC ▸            Off / On — включение сетевого интерфейса
```

## Опции

| Пункт | Значения | По умолчанию | Описание |
|-------|----------|--------------|----------|
| ESP01 › GPIO | пары TX/RX платы | плата-зависимо | Пин UART к ESP. Конфликтные пары помечены (например `off: NESPAD`) — смена требует перезагрузки |
| ESP01 › Baud | 115200 / 230400 / 460800 / 921600 | 115200 | Скорость UART. Выше = быстрее передача (~8× на 921600). Меняется на лету через `AT+UART_CUR` |
| ESP01 › Time zone | UTC−12 … UTC+14 | UTC+0 | Часовой пояс для SNTP |
| ESP01 › Sync time | — | — | Синхронизация SNTP по запросу (нужен WiFi + включённый RTC). Также авто при коннекте/буте |
| WiFi | — | — | Не подключён → скан и пароль → коннект (+ авто-синк времени); подключён → показ SSID/IP, отключение |
| FTP Server | — | — | Расшаривает SD-карту в локальную сеть по FTP (анонимно, активный режим). Эмуляция на паузе; **ESC** останавливает |
| ZiFi NIC | Off / On | Off | Включает сетевой интерфейс. Хранится в NVS |

> О скорости: **921600** даёт максимум, но без аппаратного flow control (ESP-01S не
> выводит RTS/CTS) на плохих проводах возможны единичные сбои байта — у SFTP это видно
> как `MAC mismatch` и разрыв сессии (FTP такое не заметит). Если ловишь сбои — выбери
> **460800** или ниже.

## File transfer (FTP / SFTP)

Нужно активное WiFi-соединение (тумблер **ZiFi NIC** независим — передача файлов работает
и при включённом, и при выключенном NIC).

**Network → File transfer** → выбор протокола (FTP / SFTP) → ввод хоста, пользователя,
порта и пароля. Пароль вводится **звёздочками**; **TAB** показывает/скрывает его.
Для SFTP при первом подключении показывается отпечаток ключа хоста (**SHA-256**) —
доверие сохраняется в `known_hosts` на SD (TOFU); при смене ключа подключение
блокируется (защита от MITM).

Браузер удалённых файлов (память ограничена — индекс листинга на SD, как у файлового
браузера SD-карты):

| Клавиша | Действие |
|---------|----------|
| ↑ ↓ / PgUp PgDn / Home End | навигация |
| Enter (на папке) | войти в каталог |
| Enter (на файле) | скачать → выбор папки назначения на SD |
| **F5** | копировать файл/папку (папку — рекурсивно) → выбор папки на SD |
| **F8 / Del** | удалить файл/папку (с подтверждением) |
| `[Upload file here]` | залить файл с SD в текущий удалённый каталог |
| `..` | на уровень вверх |
| Esc | выход |

Последние выбранные папки upload/download запоминаются (в `wifi.cfg`). Скачанное по
умолчанию кладётся в `/spec`.

## FTP-сервер (расшаривание SD-карты)

Обратное к File transfer: устройство становится **FTP-сервером** и расшаривает **всю
SD-карту** в локальную сеть — ПК может её просматривать и заливать/скачивать файлы.
Нужно активное WiFi-соединение.

**Network → FTP Server** запускает сервер на **порту 21** и открывает живой
**лог-терминал** с деталями подключения (`ftp://<ip>:21`, пользователь `anonymous`) и
каждой командой/ответом. Эмуляция ZX-Spectrum при этом **на паузе**; нажми **ESC**,
чтобы остановить сервер и продолжить.

- **Анонимно** — принимается любой логин/пароль (например, `anonymous` с пустым
  паролем). Полный доступ к SD на чтение и запись.
- **Только активный режим.** Прошивка ESP-AT даёт лишь один слушающий порт, поэтому
  data-соединение открывается **исходящим** к клиенту. Настрой FTP-клиент на
  **активный** (не пассивный) режим. В локальной сети работает сразу; за NAT/файрволом
  может не пройти.
- **Один клиент за раз.** Только бинарная передача (`TYPE I`).
- Поддерживаемые команды: листинг (`LIST`/`NLST`), скачивание (`RETR`), закачка
  (`STOR`/`APPE`), удаление (`DELE`), создание/удаление папки (`MKD`/`RMD`),
  переименование (`RNFR`/`RNTO`), `SIZE`, `CWD`/`CDUP`, `PWD`.

Пример с консольным клиентом `ftp`:

```
ftp> open <ip-устройства> 21
Name: anonymous
Password:           (просто Enter)
ftp> binary
ftp> ls
ftp> get game.tap
ftp> put snapshot.z80
ftp> bye
```

> **FileZilla / GUI-клиенты:** включи режим *Active* (Site Manager → Transfer Settings →
> Active) и вход *Anonymous* — в пассивном режиме data-соединение не откроется.

Постоянных настроек нет: FTP-сервер — разовое действие без собственного конфига.

## Схема подключения ESP-01S

Достаточно **4 проводов**. Логика обеих сторон **3.3 В** — переходник уровней не нужен.
**TX и RX перекрещиваются.**

```
   ESP-01S                       RP2350 (пины — см. таблицу ниже)
   TX   ───────────────────────►  RX    (zifi_rx, нечётный пин = tx+1)
   RX   ◄───────────────────────  TX    (zifi_tx, чётный пин)
   GND  ───── GND
   VCC  ───── 3V3                 (стабильные 3.3 В)

   EN/CH_PD, RST, GPIO0, GPIO2 — НЕ подключать
```

> **Питание.** ESP-01S при передаче по WiFi потребляет всплесками до ~300 мА. Питай
> от устойчивого источника 3.3 В и поставь конденсатор **100–470 мкФ** у вывода VCC —
> иначе возможны перезагрузки/просадки. Линия 3V3 самой Pico может быть на грани.

### Пины по платам (по умолчанию)

Пару можно сменить в **Network → ESP01 → GPIO**. TX — чётный пин, RX — его нечётный сосед.

| Плата | TX / RX (умолч.) | UART | Примечание |
|-------|------------------|------|------------|
| **PICO_DV** | **0 / 1** | UART0 | выделенный разъём ZiFi |
| **MURM2** | **20 / 21** | UART1 | занимает пины NESPAD |
| **PICO_PC** | **20 / 21** | UART1 | занимает пины NESPAD; альт. `2/3` (QWST1), `10/11` |
| **ZERO2** | **24 / 25** | UART1 | свободные |
| **MURM-1 (RP2350)** | **16 / 17** | UART0 | занимает пины NESPAD |

Полные GPIO-карты плат: [Платы и распиновка](../hardware/boards.md).

## Софт

Клиентского софта на стороне Spectrum для File transfer не нужно — всё делается из OSD.
Для **ZiFi NIC** (сеть внутри ZX-Spectrum-программ) используется терминал/драйверы **MRF**:

- **MRF (Moon Rabbit Firmware / terminal)**: <https://zxart.ee/eng/software/prikladnoe-po/mrf/tabs:releases/>

## Файлы на SD

| Путь | Назначение |
|------|------------|
| `/.config/pico-spec/wifi.cfg` | Настройки WiFi + сети (ключи ниже). Старый `/wifi.cfg` читается как fallback |
| `/.config/pico-spec/known_hosts` | Доверие к ключам хостов SFTP (TOFU): строки `host base64(SHA-256)` по серверу |
| `/spec` | Папка назначения по умолчанию для скачивания/копирования |

Ключи `wifi.cfg` (`ключ=значение`, по строке): `ssid`, `pass` (пароль WiFi), `tz`,
`autoconnect`, `baud`, `net_host`, `net_user`, `net_port`, `net_proto` (0=FTP, 1=SFTP),
`net_dl` / `net_ul` (последние папки скачивания/загрузки). Пароль **сервера** FTP/SFTP
**не** сохраняется — запрашивается каждый сеанс.
