# Hardware — Железо

> Путь в меню: **Hardware** · Платы: все · Требует: —

Информация о «железе» и сервисные тесты: параметры чипа и платы, конфигурация
эмулятора, подключённые HID-устройства, замеры скорости и разгон.

## Опции меню

| Пункт | Описание |
|-------|----------|
| Chip Info | Модель MCU, число ядер, частота, напряжение VREG. |
| Board Info | Объём flash, наличие/объём PSRAM, версия SDK. |
| Emulator Info | Текущая конфигурация: модель, видео, звук, ввод, хранилище. |
| HID devices | Список подключённых USB/PS2 устройств (клавиатуры, геймпады). |
| Speed Test ⟩ | Подменю тестов производительности (см. ниже). |
| Overclock (!) ⟩ | Подменю разгона (см. ниже). ⚠️ может привести к нестабильности. |

### Speed Test

| Тест | Что меряет |
|------|-----------|
| CPU MIPS | Производительность ядра. |
| SRAM R/W | Скорость чтения/записи SRAM. |
| PSRAM | Скорость SPI/QSPI PSRAM. |
| SD Card | Скорость SD-карты. |
| All tests | Все тесты подряд. |

### Overclock (!)

| Пункт | Описание |
|-------|----------|
| CPU Freq | Частота ядра (напр. 252 / 378 / 504 МГц). |
| VReg Voltage *(RP2350)* | Напряжение регулятора (нужно поднимать для высоких частот). |
| Flash Freq | Частота интерфейса flash. |
| PSRAM Freq | Частота PSRAM. |

> ⚠️ Высокие частоты + HDMI audio + Gigascreen могут вызывать зависание при
> переключении PLL (известная проблема, см. заметки разработчика). Меняй частоту
> осознанно.

## Схема / подключение

Полные карты GPIO всех плат — в [Платы и распиновка](../hardware/boards.md).

## Как проверить

Speed Test самодостаточен — образы не нужны. Сравнивай MIPS/скорости PSRAM при
разных значениях Overclock.
