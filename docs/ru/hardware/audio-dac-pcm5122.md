# PCM5122 (I2S аудио-ЦАП)

> [Главная](../README.md) · Платы: Waveshare RP2040/RP2350-PiZero

Внешний I2S-ЦАП PCM5122 для качественного звука на платах Waveshare PiZero.

> 🚧 Заготовка. Описать: подключение (I2C управление + I2S данные), пины
> (ZERO2: SDA=2, SCL=3, BCK=18, LCK=19, DATA=21), выбор драйвера в Audio → Audio Driver.
>
> Документация платы: https://www.waveshare.com/wiki/PCM5122-Audio-Board-A
