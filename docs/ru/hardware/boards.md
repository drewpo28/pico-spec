# Платы и распиновка

> [Главная](../README.md)

Поддерживаемые платы и карты GPIO для каждой. Полные таблицы (FIXED / REASSIGN / FREE)
с пометками о конфликтах ведутся в [CLAUDE.md](../../../CLAUDE.md) (раздел *GPIO Map*).

## Поддерживаемые платы

| Плата | MCU | GPIO | MIDI | NESPAD |
|-------|-----|------|------|--------|
| MURM2 | RP2350A | 0–29 | OK (GPIO 22) | конфликт с PSRAM |
| PICO_PC | RP2350A | 0–29 | OK (GPIO 26) | OK |
| PICO_DV | RP2350 | 0–29,47 | баг (GPIO 21=RX) | конфликт с дисплеем |
| ZERO | RP2040 | 0–28 | — (RP2040) | OK |
| ZERO2 | RP2350B | 0–47 | OK (GPIO 22) | отключён |
| MURM | RP2040 | 0–28 | — (RP2040) | OK |
